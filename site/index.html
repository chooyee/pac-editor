What is PacEditor

An embeddable page builder for developers

PacEditor is an open-source drag-and-drop page builder written in plain JavaScript. It gives your users a visual website editor inside your own app, so they can build landing pages, marketing pages and content pages without writing code. It is a lightweight Puck alternative for teams that don't use React, and it pairs with any backend or headless CMS because every page is saved as JSON.

  • Adding a page builder to an existing site
  • CMS and admin panels
  • Landing page and marketing page editors
  • SaaS apps that let customers edit pages
  • Static sites and server-rendered apps
  • React, Vue or no-framework projects

Why PacEditor

Everything you need to let people edit pages

A full visual editor that drops into the site you already have, and a renderer that turns the result into safe HTML.

  • A complete visual editor

    Block palette, drag and drop, nested layouts, a properties panel, undo and redo, and preview at desktop, tablet and phone widths.

  • Works with any stack

    Plain JavaScript. Use it on a static HTML page, a server-rendered app, or inside React, Vue or anything else.

  • Puck-compatible data

    Pages are saved in the same JSON shape as Puck, so configs, components, fields and slots carry over.

  • Safe rich text

    Rich text (via Quill) is stored as JSON, not HTML, so a saved page cannot inject markup into your site.

  • Render on the server

    The renderer has no DOM dependency. Turn page JSON into HTML in Node, Deno, Bun, edge workers or the browser.

  • Small and quick

    About 43 KB minified for the editor and renderer together. Quill is optional and loaded separately.

How it works

From empty page to published site in three steps

Add the editor

Load the stylesheet and script from a CDN, or install from npm. The editor fills the element you mount it on.

<!-- In your page -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/pac-editor@0.1/dist/pac-editor.min.css">
<div id="editor" style="height: 100vh"></div>
<script src="https://cdn.jsdelivr.net/npm/pac-editor@0.1/dist/pac-editor.min.js"></script>

Build and save

People drag in blocks and fill in fields. When they publish, you get plain JSON to store wherever you like.

PacEditor.createEditor('#editor', {
  onPublish: async data => {
    await fetch('/api/pages/home', { method: 'PUT', body: JSON.stringify(data) });
  }
});

Render the page

Turn the saved JSON into HTML on your server or in the browser, then add blocks.css to the public page.

import { render, defaultConfig } from 'pac-editor/render';

const html = render(defaultConfig, data);   // <div class="fp-site">…</div>

Add your own blocks

A block is a label, some fields and a render function that returns HTML. See the configuration guide.

const Quote = {
  label: 'Quote',
  fields: { text: { type: 'textarea', label: 'Quote' } },
  defaultProps: { text: 'Something memorable.' },
  render: p => `<blockquote>${PacEditor.esc(p.text)}</blockquote>`
};

Questions

Good to know

What is PacEditor?

PacEditor is an open-source drag-and-drop page builder written in plain JavaScript. You embed it in any web page with one script tag, and it saves pages as JSON that you render to HTML on the server or in the browser.

Is there a page builder like Puck that does not need React?

Yes. PacEditor uses the same page data format as Puck but is written in plain JavaScript, so it runs without React or a build step.

Can I render pages on the server?

Yes. Import render from pac-editor/render. It has no DOM dependency and returns an HTML string in Node, Deno, Bun or edge workers.

Can I use it with a headless CMS or my own backend?

Yes. The editor hands you JSON in onPublish, and you store it wherever you like: your own API, a database or a headless CMS.

Do I need Quill?

No. Quill adds rich text to the Text block. Without it, rich text fields fall back to a plain textarea.

Is it ready for production?

PacEditor is at version 0.x. The data format follows Puck and is expected to stay stable; the JavaScript API may still change before 1.0. See the changelog.

Is it free?

Yes. PacEditor is open source under the MIT license.
