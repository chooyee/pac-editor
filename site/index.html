PacEditor

A drag-and-drop page builder you add to any web page with one <script> tag. No React, no framework, no build step.

Try the live demo All examples GitHub

Features

  • Visual editor

    Block palette, drag and drop, nested layouts, properties panel, undo and redo, outline, and preview at desktop, tablet and mobile widths.

  • Works anywhere

    Plain JavaScript. Use it on a static HTML page, a server-rendered app, or inside React, Vue or any other framework.

  • Puck-compatible data

    Pages are stored in the same JSON shape as Puck, so configs, components, fields and slots carry over.

  • Safe rich text

    Rich text (via Quill) is stored as JSON, not HTML, so saved pages cannot inject markup.

  • Server rendering

    The renderer has no DOM dependency. Turn page JSON into HTML in Node, Deno, Bun, workers or the browser.

  • Small

    About 43 KB minified for the editor and renderer together. Quill is optional.

Quick start

Add the stylesheet and script, then mount the editor on an element:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/pac-editor@0.1/dist/pac-editor.min.css">
<div id="editor" style="height: 100vh"></div>

<script src="https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.js"></script>
<script src="https://cdn.jsdelivr.net/npm/pac-editor@0.1/dist/pac-editor.min.js"></script>
<script>
  PacEditor.createEditor('#editor', {
    onPublish: async data => {
      await fetch('/api/pages/home', { method: 'PUT', body: JSON.stringify(data) });
    }
  });
</script>

Or install from npm with npm install pac-editor quill. Read the getting started guide.

Your own blocks

A block is a label, some fields and a render function that returns HTML:

const Quote = {
  label: 'Quote',
  fields: { text: { type: 'textarea', label: 'Quote' } },
  defaultProps: { text: 'Something memorable.' },
  render: p => `<blockquote>${PacEditor.esc(p.text)}</blockquote>`
};

See the configuration guide for fields, arrays, slots and custom fields.

Questions

How is PacEditor different from Puck?
Puck is a React component. PacEditor uses the same page data format but is written in plain JavaScript, so it runs without React or a build step.
Can I render pages on the server?
Yes. Import render from pac-editor/render. It has no DOM dependency and returns an HTML string.
Where are pages saved?
Wherever you choose. The editor gives you JSON in onPublish, and you send it to your own server or storage.
