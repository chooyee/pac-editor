PacEditor examples

Live examples of PacEditor. To run them locally, use npm run dev and open http://localhost:8000/examples/.

  • Basic — script tags, inline page data, autosaved draft. Also works when opened as a file.
  • Demo — the full sample page; “Publish & view” renders it on a public page.
  • Custom blocks — ES module import, three new blocks (rich text, array and custom fields), one block removed.
  • node examples/server-render/render.mjs — render page data to static HTML on the server.
